# 大麦抢票助手（个人自用）

基于 **Python + Playwright** 的大麦网（detail.damai.cn）定时抢票工具：提前登录选场，开售瞬间自动刷新点击，一路自动到**提交订单为止**，然后响铃提醒你手动付款。

## 边界与红线

- **仅个人自用**。禁止转卖票务或提供代抢服务（违法）。
- **不逆向协议、不破解签名、不绕过验证码**：遇到滑块验证码会响铃暂停，由你人工完成。
- **支付不自动化**：提交订单后需你在 15 分钟内手动付款。
- 刷新限速 ≥500ms + 随机抖动，尽量模拟人工节奏，但**无法保证零风控风险**（账号可能受限）。
- 定位是"比手快、提高概率"，热门演出**不保证必中**。

## 环境准备

1. 安装 Python 3.11+（勾选 Add to PATH）
2. 本机需已安装 **Google Chrome**（脚本驱动真实 Chrome，不用捆绑的 Chromium）
3. 安装依赖：

```bash
pip install -r requirements.txt
```

## 使用步骤

### 第一步：填写配置

编辑 `config.yaml`：

| 字段 | 说明 |
|---|---|
| `show_url` | 演出详情页链接（大麦网页版地址栏复制） |
| `session` | 场次关键字，如 `"10月25日"`（模糊匹配页面文字） |
| `ticket` | 票档关键字，如 `"680元"` |
| `quantity` | 购票数量（1~6） |
| `sale_time` | 开售时间，北京时间，如 `"2026-10-12 10:00:00"` |

### 第二步：登录（可提前几天做）

```bash
python main.py --check-login
```

浏览器会打开大麦首页，用手机大麦/淘宝 App 扫码登录。登录态保存在 `profile/` 目录（已加入 .gitignore，含账号 Cookie，**不要分享给任何人**），之后免扫码。

### 第三步：演练（强烈建议）

找一场**正在售卖中**的演出填好配置，跑：

```bash
python main.py --dry-run
```

它会跳过开售等待，直接走完 选票档 → 立即购买 → 订单确认页 的完整链路并停下（**不提交订单**）。用于验证选择器是否命中、票档数量观演人是否正确。

### 第四步：正式抢票

开售前 5~10 分钟运行：

```bash
python main.py
```

流程：打开详情页 → 校验登录 → 预选场次票档 → 与大麦服务器对时 → 倒计时待命 → 开售瞬间刷新点击 → 自动进订单页提交 → **响铃提醒你在 15 分钟内手动付款**。

## 常见问题

- **页面改版导致找不到按钮/选项？** 所有选择器集中在 `src/pages/detail_page.py` 和 `src/pages/order_page.py`，每个操作都有多条候选策略；报错信息会提示你更新哪个文件。
- **中途弹出滑块验证码？** 脚本会响铃并暂停，你在浏览器里人工拖完滑块，脚本自动继续。
- **本地时钟不准？** 脚本每次运行都会与大麦服务器对时（HTTP Date 头），按服务器时间触发，本地时钟偏差几分钟也不影响。
- **想抢猫眼？** 猫眼无 PC 购票网页，需另做 Android 真机/模拟器 + 图像识别方案（本项目未覆盖）。

## 项目结构

```
qiangpiao/
├── main.py                # CLI 入口
├── config.yaml            # 演出配置
├── requirements.txt
└── src/
    ├── config.py          # 配置加载校验
    ├── time_sync.py       # 服务器时间校准
    ├── browser.py         # 持久化浏览器上下文 / 登录态
    ├── grabber.py         # 主流程状态机
    ├── notify.py          # 响铃 + Windows 桌面通知
    └── pages/
        ├── detail_page.py # 详情页选择器与操作
        └── order_page.py  # 订单页选择器与操作
```
